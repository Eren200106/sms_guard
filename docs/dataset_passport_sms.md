# Паспорт набора данных: UCI SMS Spam Collection

| Пункт | Значение |
|---|---|
| Источник | UCI Machine Learning Repository |
| Ссылка | https://archive.ics.uci.edu/dataset/228/sms+spam+collection |
| Лицензия | _проверьте на странице набора и впишите (на странице указана CC BY 4.0)_ |
| Дата загрузки | _впишите дату_ |
| Язык | английский |
| Объём | _впишите точное число строк после `load_sms`_ (по описанию ≈ 5 574) |
| Классы | ham (0) — безопасное, spam (1) — спам/мошенничество |
| Известные ограничения | только английский язык; спам ≠ мошенничество в строгом смысле; набор старый (по тематике и стилю) |

Структура: файл `SMSSpamCollection`, разделитель — табуляция, два столбца: метка и текст.
После загрузки: столбцы `id`, `text`, `label`.

- 100 SMS на русском и 50 на казахском, 50% мошеннических; все сообщения искусственные.
