# Паспорт набора данных: URL

| Пункт | Значение |
|---|---|
| Набор | PhiUSIIL Phishing URL Dataset (основной вариант) |
| Ссылка | https://archive.ics.uci.edu/dataset/967/phiusiil+phishing+url+dataset |
| Лицензия | _проверьте на странице набора и впишите_ |
| Дата загрузки | _впишите_ |
| Объём | _точное число после загрузки_ (по описанию ≈ 235 тыс.) |
| Метки | в источнике: 1 — легитимный, 0 — фишинг. В проекте инвертировано: 0 — безопасный, 1 — фишинг |
| Используются | только признаки, вычислимые из строки URL (`ml/url_features.py`) |

## Очистки
Описание в `docs/url_eda.md` (создаётся командой `python -m ml.data.prepare_url`):
удалены пустые, некорректные и дублирующиеся URL; домен приведён к нижнему регистру;
схема и `www.` убраны (артефакт разметки), признак `is_https` исключён из модели;
разбиение 70/15/15 по зарегистрированному домену (GroupShuffleSplit).

Для Kaggle Malicious URLs: benign → 0, остальные классы (phishing, malware, defacement) → 1,
так как все они считаются опасными для пользователя.
